# Managing Firewall Services (HTTP, SSH, FTP)

## Aim

To allow and block predefined services using firewalld.

---

## Theory

Firewalld is a firewall management tool available in Linux.

It provides predefined services:

- http
- https
- ssh
- ftp
- samba

Services can be enabled or disabled using firewall-cmd.
